# Мини-CRM «Объекты и задачи»

Веб-приложение для управления строительными объектами и задачами с ролевым доступом (Постановщик / Исполнитель) и строгим циклом статусов задач.

## Стек технологий
- **Frontend:** React 19, TypeScript, Vite, Ant Design, React Router DOM
- **Backend / Database:** Supabase (PostgreSQL, Row Level Security, Triggers, Auth)

---

## Реализованный функционал

1. **Ролевая модель доступа:**
   - **Постановщик (`manager`):** создание, редактирование и удаление объектов; создание задач с назначением исполнителя; приемка задач («Принята») или возврат на доработку («На доработке» с обязательным комментарием); полный доступ ко всем данным компании.
   - **Исполнитель (`worker`):** просмотр только своих задач и объектов, в которых у него есть задачи; перевод задач в статус «В работе» и отправка «На проверку».

2. **Безопасность данных (на уровне базы PostgreSQL):**
   - **RLS (Row Level Security):** исполнитель физически не может прочитать или изменить чужие задачи или объекты через Supabase API.
   - **Контроль переходов статусов в триггере БД:** любые запрещенные переходы статусов прерываются ошибкой на уровне PostgreSQL (`BEFORE UPDATE TRIGGER`).
   - **Иммутабельная история:** таблица `task_history` доступна через API только для чтения. Все записи в историю формируются автоматически триггерами базы данных.
   - **Секретные ключи:** во фронтенде используется исключительно публичный `anon` ключ.

3. **Экраны приложения:**
   - Экран входа по email и паролю.
   - Список строительных объектов (карточки с адресами и переходом к задачам).
   - Карточка объекта со списком задач, фильтрацией по статусам и созданием новых задач.
   - Карточка задачи с отображением только тех кнопок действий, которые разрешены текущему пользователю в текущем статусе задачи, модальным окном обязательного комментария и подробным таймлайном истории.
   - Раздел «Мои задачи» для быстрого доступа исполнителя к назначенным задачам.

## Запуск проекта локально

### 1. Клонирование репозитория и установка зависимостей
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd mini-crm
npm install --legacy-peer-deps
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта со следующими переменными:
```env
VITE_SUPABASE_URL=https://<your-project-id>.supabase.co
VITE_SUPABASE_ANON_KEY=<your-anon-key>
```

### 3. Инициализация базы данных
Выполните SQL-скрипт из файла `schema.sql` в **Supabase SQL Editor**.

### 4. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:5173`.

### 5. Сборка для продакшена
```bash
npm run build
```
Папка `dist/` готова к деплою на Vercel, Netlify или любой статический хостинг.
